AI Blueprint · Edition 2026–27Chapter 01
Prompt 07

Develop a Space Programme with Area Schedule

Purpose

To create a detailed space programme and area statement for a given project.

Ideal point of use

Concept design / pre-design stage.

Inputs required

  • Project type and scale
  • Functional requirements
  • Target user group
  • Any specific constraints (e.g. Vastu, plot size)
Copy-ready prompt (for ChatGPT)
Create a detailed space programme and area schedule for a G+2 premium residence on a 40 ft × 60 ft (2,400 sq. ft) plot for a family of 5. Include built-up area, room sizes, functional relationships, and a summary table with floor-wise areas. Suggest an efficient spatial layout and key design considerations for the local climate.
Illustrative output (sample): space programme & area statement
SpaceArea (sq. ft)

Master Bedroom280

  • Add your local bye-law setbacks and FAR so the schedule stays within what you can build.
  • Follow up with: “Now split this floor-wise for G+2 and suggest adjacencies for each floor.”
